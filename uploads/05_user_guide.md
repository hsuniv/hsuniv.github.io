# 한성대학교 IT 헬프데스크 AI 챗봇 — 전체 운영 가이드

> **이 문서 대상**
> - **1~3장**: 시스템 담당자 (서버 관리, 데이터 운영, 장애 대응)
> - **4~5장**: 일반 사용자 · 행정부서 담당자 (챗봇 이용, 한계 이해)

---

## 1장. 시스템 전체 개요 (담당자용)

### 이 시스템이 하는 일

교직원이 IT 관련 질문을 하면, 한성대 홈페이지 IT 매뉴얼·공지사항·부서 연락처를 검색해 AI가 자동으로 답변해주는 시스템이다.

```
[교직원]
  │
  ├── 네이버 웍스 채팅 ─────────┐
  │                              ▼
  └── 웹 브라우저 접속 ──→ [IT 헬프데스크 봇 서버]
       help.hansung.ac.kr            │
                               ① 질문 키워드 검색
                               ② 관련 자료 조회
                               ③ AI 답변 생성
                                     │
                                     ▼
                              [교직원에게 답변 전송]
```

### 구성 요소 한눈에 보기

| 구성 요소 | 역할 | 위치 |
|----------|------|------|
| Flask 웹 서버 | 질문 수신·답변 전송 처리 | `/opt/it-helpdesk-bot/app.py` |
| Apache 웹 서버 | 외부(HTTPS) → 내부 Flask 연결, 관리자 페이지 인증 | Rocky Linux 서버 |
| Claude AI | 검색된 자료 기반 자연어 답변 생성 | Anthropic API (외부) |
| 크롤러 | 한성대 홈페이지에서 최신 자료 자동 수집 | `/opt/it-helpdesk-bot/tools/` |
| 데이터 파일 | 수집된 자료 저장 | `/opt/it-helpdesk-bot/data/` |
| 관리자 대시보드 | 크롤링 현황·질문 로그·통계 열람 | `https://help.hansung.ac.kr/hsmgmt` |

## 2장. 데이터 흐름과 자동화 (담당자용)

### 2-1. 데이터 수집 자동화 (크론)

매일 서버에서 자동으로 실행되는 작업:

```
매일 오전 6시 00분  → 게시판 크롤링 (IT 매뉴얼 + IT 보안공지 + 전체공지)
매일 오전 6시 05분  → 홈페이지 정적 페이지 크롤링 (IT서비스 안내, 대학생활 등)
매주 월요일 6시 10분 → 행정부서 통합전화부 PDF 파싱 (연락처 갱신)
매일 새벽 3시 00분  → 질문 로그 90일 초과 항목 자동 삭제
```

> **테스트 기간 중**: 1시간 간격으로도 추가 실행 중 (안정화 후 제거 예정)

### 2-2. 수집 대상과 저장 위치

| 수집 대상 | 수집 스크립트 | 저장 파일 | 수집 주기 |
|----------|------------|---------|---------|
| IT 매뉴얼 게시판 (4016) | `crawl_faq.py` | `data/faq.json` | 매일 |
| IT 보안공지 게시판 (4017) | `crawl_faq.py` | `data/faq.json` | 매일 |
| 전체공지 게시판 (6172) | `crawl_faq.py` | `data/faq.json` | 매일 |
| 홈페이지 정적 페이지 21개 | `crawl_pages.py` | `data/pages.json` | 매일 |
| 행정부서 통합전화부 PDF | `parse_admin_staff.py` | `data/admin_staff_structured.json` | 주 1회 |
| 교직원 질문·답변 기록 | (서버가 자동 저장) | `data/question_log.jsonl` | 실시간 |

### 2-3. 질문이 들어오면 어떻게 처리되나

사용자가 질문을 보내면 아래 순서로 처리된다:

```
1. 질문 텍스트 수신
       ↓
2. 키워드 검색 — faq.json + pages.json에서 관련 게시글 최대 3건 추출
       ↓
3. 연락처 검색 — 부서·팀 이름이 포함된 경우 admin_staff_structured.json 조회
                  IT 관련 질문이면 it_services.json도 조회
       ↓
4. Claude AI 호출 — 검색된 자료를 문맥으로 넣어 자연어 답변 생성
       ↓
5. 답변 전송 — 웹 화면 또는 네이버 웍스 채팅으로 전송
       ↓
6. 로그 기록 — 질문·답변 미리보기·출처 수를 question_log.jsonl에 저장
```

### 2-4. 첨부파일도 읽나

게시글에 첨부된 파일도 내용을 추출해서 검색 대상에 포함시킨다.

| 지원 형식 | 처리 방식 |
|---------|---------|
| PDF | pdfplumber 라이브러리로 텍스트 추출 |
| PPTX (파워포인트) | 슬라이드 텍스트 추출 |
| DOCX (워드) | 단락 텍스트 추출 |
| TXT | 그대로 읽음 |

> HWP, 이미지(JPG, PNG), 스캔 PDF는 텍스트 추출 불가 — 해당 파일의 내용은 답변에 활용되지 않는다.

## 3장. 관리자 대시보드 사용법 (담당자용)

### 3-1. 접속 방법

| 환경 | 주소 | 인증 |
|------|------|------|
| 운영 서버 (교내 네트워크) | `https://help.hansung.ac.kr/hsmgmt` | Apache Basic Auth (아이디/비밀번호) |
| 로컬 개발 PC | `http://localhost:5001/hsmgmt` | 없음 (직접 접속) |

> **교내 IP(220.66.102.x / 220.66.103.x)에서만 접속 가능.** 외부망에서는 열리지 않는다.

### 3-2. 탭별 기능

**[크롤링 현황 탭]**
- 마지막 크롤링 시각과 수집 건수 확인 (faq.json, pages.json)
- 크롤링 로그 확인 (기본 20줄, "전체 로그 펼치기" 버튼으로 500줄까지 확장)
- 크롤러가 정상 실행됐는지, 오류가 없는지 확인할 때 사용

**[Q&A 로그 탭]**
- 교직원이 실제로 한 질문과 AI 답변 미리보기 열람
- 날짜·채널(웹/웍스) 필터로 원하는 기간 조회 가능
- 답변 품질 개선, 자주 묻는 질문 파악에 활용

**[일별 통계 탭]**
- 최근 30일간 웹/네이버 웍스 채널별 질문 수 현황

**[카테고리 통계 탭]**
- 질문을 네트워크/WiFi, 이메일, 계정/비밀번호, AI허브 등 8개 카테고리로 분류한 통계
- 전체 기간 또는 최근 30일 선택 가능

### 3-3. 크롤링 데이터 수동 갱신 방법

게시판에 새 매뉴얼이 올라갔는데 크론 실행 전에 바로 반영하고 싶을 때:

```bash
# 서버 접속 후 hs 계정으로
cd /opt/it-helpdesk-bot

# FAQ 게시판만 즉시 재수집
venv/bin/python -u tools/crawl_faq.py

# 정적 페이지만 즉시 재수집
venv/bin/python -u tools/crawl_pages.py

# 행정부서 연락처 즉시 갱신
venv/bin/python -u tools/parse_admin_staff.py
```

> 서버 재시작 없이 다음 질문부터 바로 반영된다.

### 3-4. 크롤링 대상 게시판·페이지 추가/제거

코드를 수정하지 않고, 서버의 `.env` 파일만 편집하면 된다.

```
# .env (서버: /opt/it-helpdesk-bot/.env)

# 게시판 추가: 쉼표로 구분해서 URL 추가
BOARD_URLS_HASH=https://hansung.ac.kr/info/4016/subview.do
BOARD_URLS_NEW=https://hansung.ac.kr/info/4017/subview.do,https://hansung.ac.kr/info/6172/subview.do

# 정적 페이지 추가: 원하는 섹션 첫 페이지 URL 추가
PAGE_ROOTS=https://www.hansung.ac.kr/hansung/6298/subview.do,...
```

변경 후 서버 재시작(`systemctl restart it-helpdesk-bot`)하면 다음 크론 실행부터 반영된다.

### 3-5. 서비스 상태 확인

```bash
# 서비스 동작 여부
systemctl status it-helpdesk-bot

# 최근 크롤링 로그
tail -100 /opt/it-helpdesk-bot/logs/crawl.log

# API 정상 응답 확인
curl https://help.hansung.ac.kr/api/health
```

## 4장. 일반 사용자 이용 가이드

### 4-1. 두 가지 이용 방법

**방법 ① 네이버 웍스 채팅**
- 네이버 웍스(Line Works)에서 "IT 헬프데스크" 봇을 찾아 채팅 전송
- 스마트폰 또는 PC에서 모두 이용 가능

**방법 ② 웹 브라우저**
- 주소: `https://help.hansung.ac.kr`
- 별도 로그인 없이 바로 질문 가능

### 4-2. 어떤 질문을 할 수 있나

주로 IT 관련 질문에 잘 답변한다:

| 질문 유형 | 예시 |
|---------|------|
| Wi-Fi 연결 | "교내 와이파이 연결하는 방법이 뭔가요?" |
| 웹메일 | "구글 웹메일 비밀번호 바꾸는 법" |
| 오피스 설치 | "Office 365 어디서 설치하나요?" |
| 계정·비밀번호 | "종합정보시스템 비밀번호 초기화" |
| 프린터·복합기 | "도서관 복합기 스캔 방법" |
| AI Hub | "HSU AI Hub 사용법" |
| 웹메일 첨부파일 | "웹메일에서 첨부파일 용량 제한이 얼마나 되나요?" |
| 부서 연락처 | "학사운영팀 전화번호가 어떻게 되나요?" |

### 4-3. 답변 구조 이해하기

챗봇은 아래 형식으로 답변한다:

```
[핵심 답변 내용]

📄 참고: IT 매뉴얼 게시글 제목
☎ 문의: IT인프라팀 02-760-4291
```

- **📄 참고**: 답변 근거가 된 게시글. 클릭하면 원문으로 이동 가능.
- **☎ 문의**: 더 도움이 필요할 때 연락할 담당 부서 전화번호.

### 4-4. 대화 맥락 유지

연속 질문도 가능하다. 이전 대화를 기억하기 때문에:

```
나:  "오피스 365 설치 방법 알려줘"
봇:  "① 포털 접속 → ② ... 설치"
나:  "모바일에서도 되나?"   ← "모바일에서도 오피스 365 설치 되나요?"로 해석
봇:  "네, 모바일 앱으로도 ..."
```

> 최근 5턴까지 기억한다. 새로운 주제로 넘어갈 때는 처음부터 다시 질문하는 것이 더 정확하다.

## 5장. 챗봇의 한계와 올바른 활용법

### 5-1. 이 챗봇이 잘 못하는 것

| 한계 | 이유 | 대안 |
|------|------|------|
| 개인 계정 잠금 해제 | 개인 식별이 필요한 업무는 직접 처리 불가 | IT인프라팀(02-760-4291) 직접 문의 |
| 실시간 장애 상황 | 크롤링된 공지 기준이므로 방금 발생한 장애는 모를 수 있음 | 공지사항 직접 확인 |
| HWP·스캔PDF 내용 | 해당 형식은 텍스트 추출 불가 | 첨부파일 직접 다운로드 후 확인 |
| IT 외 업무 (인사, 회계 등) | IT 분야로 특화된 시스템 | 해당 부서 직접 문의 |
| 최신 정보 반영 지연 | 게시판 크롤링 주기(매일 1회)만큼 늦을 수 있음 | 중요 공지는 게시판 직접 확인 |

### 5-2. 답변이 틀리거나 부족할 때

1. **재질문**: "좀 더 자세히 알려줘" 또는 질문을 다르게 표현해서 다시 시도
2. **직접 문의**: IT인프라팀 내선 **02-760-4291**
3. **게시판 확인**: `https://hansung.ac.kr/info/4016/subview.do` (IT 매뉴얼)

### 5-3. 행정부서 담당자 — 자기 부서 연락처가 틀렸을 때

행정부서 연락처는 한성대 홈페이지의 **통합전화부 PDF**에서 자동으로 읽어온다.  
(출처: `https://www.hansung.ac.kr/hansung/6061/subview.do`)

챗봇에 잘못된 번호가 표시된다면:
1. 홈페이지 통합전화부 PDF가 최신 정보인지 확인
2. PDF가 업데이트되면 챗봇도 다음 월요일 크론 실행 시 자동 반영
3. 즉시 반영이 필요하면 IT인프라팀 담당자에게 수동 갱신 요청

## 부록. 데이터 보관 정책

- 질문 로그는 **90일간 보관** 후 자동 삭제 (매일 새벽 3시 실행)
- 질문과 함께 사용자 ID는 저장되지 않음 (익명)
- 저장 내용: 질문 원문, 답변 앞 150자, 출처 수, 채널(웹/웍스), 시각
- 저장 목적: AI 답변 품질 개선 및 자주 묻는 질문 파악 (내부 개선용)
